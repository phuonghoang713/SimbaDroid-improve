SimbaDroid is an SMB server for Android, allowing you to access the contents of your storage (both internal storage or an external SD card) from your computer via wi-fi.

SMB2 and SMB3 are supported, including signing and encryption, as well as the old SMB1 protocol for devices that need it.

Root is optional. As on all Unixoid operating systems, an app cannot open a port < 1024 without it, and the default SMB port is 445. With root, SimbaDroid redirects that port and is reachable like any other file server. Without root it is reachable on port 4450, so you need an SMB client which allows configuring the port: macOS, Linux, most file manager apps, and Windows 11 from version 24H2 (net use Z: \\<address>\Internal /TCPPORT:4450). The app shows the address and port to use.

Shares for the internal storage ("Internal") as well as an external SD card ("External", if one is detected) are set up automatically. By default they are accessible without authentication, so be careful about using this app in public networks. You can set a user name and password in the settings; this is also required by current Windows versions, which no longer accept servers without a login.

READ/WRITE/MANAGE_EXTERNAL_STORAGE is required for filesystem access.
